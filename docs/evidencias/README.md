# Evidências

Guardar aqui relatórios sanitizados por história (por exemplo H01-build.md), ou links de CI referenciados no progresso. Registrar comando, ambiente, data, commit e resultado real. Não há evidência de software neste pacote inicial. Nunca anexar tokens, dados de cartão, dados pessoais reais ou dumps produtivos. Evidência externa confidencial permanece em local controlado, com referência e responsável no registro.
